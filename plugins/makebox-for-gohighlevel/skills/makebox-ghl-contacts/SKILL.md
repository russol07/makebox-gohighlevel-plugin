name: makebox-ghl-contacts
description: Find or inspect GoHighLevel contacts, related notes and tasks in the authorized location; prepare supported updates from the user's instructions.
---

Confirm the location when ambiguous. Discover the contact search or detail tool and inspect its current schema. For contact search, the API may require the selected location ID in the request body; use the verified location summary, never a different location. Return only relevant fields; distinguish a returned page from a total. Ask the user to disambiguate before changing the wrong contact. Check provider response and read back any supported update. If writes are disabled, report the block and provide an actionable draft rather than claiming success.
