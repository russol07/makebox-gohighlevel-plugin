name: makebox-ghl-agency
description: Inspect authorized agency-level resources and switch among permitted GoHighLevel locations.
---

An agency owner connects an agency-level token in their workspace, then connects each location with its own location-level token. Users authenticate individually and select a resource through the MCP authorization flow. A location token and agency token are not interchangeable. Verify the selected organization and resource before a read; do not assume access to every sub-account. Discover actual agency tools and respect per-user module permissions and the hosted read-only gate.
